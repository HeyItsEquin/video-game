# Climbing Game Demo
Very early demo for a game about, well... climbing.
Climb up the tower to the top because you feel like it.
We do not want to work on this anymore cuz we are done. It started off being some fun project and now we hate it. 
There are no issues with the game and if you find any your just really bad at it.

Made with Unity.

## How to play:
  Download and unzip the latest release
  Launch the game

### Controls:
  ESC - Open the pause menu
  WASD - Movement
  Left Click - Grab onto ledge/object
  R - Reset your character, go back to the last checkpoint (Temporary feature, will be removed in the future)
